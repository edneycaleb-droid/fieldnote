**https://github.com/edneycaleb-droid/hermes-ai-knowledge-ops/blob/main/00_AI_ECOSYSTEM_INDEX.md**

It contains the organized decisions, architecture patterns, security classifications, and integration priorities for:

- Artificial-Intelligence-Universe and other discovery feeds
- mandatory identity, maintenance, license, cost, security, sandbox, testing, and rollback gates
- the high-risk quarantine decision for `Kimi-ai-K3/kimi-k3`
- reusable modular-skill and critic-loop patterns
- the standard structured worker-output contract

## Required repository policy

Before introducing a new model, MCP server, agent framework, provider, skill, package, executable, or automation service:

1. Review the canonical index.
2. Verify the official source and ownership.
3. Record a decision: **ADOPT, PILOT, WATCH, REFERENCE, QUARANTINE, or REJECT**.
4. Test in an isolated branch, worktree, container, or VM.
5. Require tests, evidence, security review, rollback instructions, and a pull request.

This root file is intentionally named `00_AI_ECOSYSTEM_INDEX.md` so it remains easy to find.
